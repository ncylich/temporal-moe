The same slice of wall-clock, two memory regimes

Both panels are drawn at the identical time scale, so horizontal distance is directly comparable. Both now run the same repacked ARM kernel — the only difference is that the temporal engine streams one expert per layer per token from flash storage, while the baseline holds its whole expert pool in RAM. The baseline is the largest MoE that fits resident on this phone (112 experts, same K=18 active, same per-expert width) — not a dense stand-in. In this 7 ms window the resident baseline clears 15 layers; the temporal engine clears 7.8.
